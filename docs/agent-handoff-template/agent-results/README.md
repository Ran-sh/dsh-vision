# Agent results

Durable reports from completed ACTIVE tasks live here when the task requires one.

Recommended naming:

```text
<agent>-<task>-report.md
<agent>-<task>-review.md
```

A report should be decision-oriented, not a transcript. Include source SHA, environment when relevant, work/tests actually performed, results, evidence, blockers, known limitations, files changed, result commit SHA, and recommended next action.

Never include secrets or private chain-of-thought.
